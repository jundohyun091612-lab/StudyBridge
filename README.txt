[ 이게 뭐죠? ]
올린 수업 자료를 단원(슬롯)에 맞춰 정리하고, 11개 항목으로 요약·문제까지
만들어주고, 시험 날짜에 맞춰 공부 계획표를 짜주는 프로그램입니다.


----------------------------------------------------------------
[ 처음 한 번만: OpenAI 키 넣기 ]
----------------------------------------------------------------
1. 이 폴더 안의  OpenAI_Key.txt  파일을 메모장으로 엽니다.
2. 안에 있는 글자를 지우고, 본인 OpenAI 키를 붙여넣고 저장합니다.
   (키가 없으면 화면은 열리지만 AI 기능은 작동하지 않습니다.)


----------------------------------------------------------------
[ 사진/스캔 글자 읽기: Tesseract (권장 설치) ]
----------------------------------------------------------------
노트 사진이나 스캔 PDF의 글자는 먼저 PC에 설치된 Tesseract(무료, 오프라인)로
읽고, 잘 안 읽히는 것(흐릿/손글씨)만 OpenAI에 보냅니다. 이렇게 하면 한 번에
수백 장을 올려도 요금 폭탄이나 "분당 한도 초과(429)"가 안 납니다.

* 설치: https://github.com/UB-Mannheim/tesseract/wiki 에서 윈도우 인스톨러를 받아
  설치하면 됩니다. (보통 C:\Program Files\Tesseract-OCR 에 설치됨 — PATH 안 잡혀도
  앱이 이 경로를 자동으로 찾습니다.)
* 설치 안 해도 앱은 돌아갑니다. 다만 그 경우 사진/스캔은 전부 OpenAI로 가서
  느리고 비용이 더 들 수 있습니다.

[ 실행하기 ]
----------------------------------------------------------------
* 압축을 풀고, 폴더 안의 모든 파일이 한 폴더에 있어야 합니다.

방법 1 (추천):  start.bat  를 더블클릭.
방법 2       :  run.ps1  을 우클릭 -> "PowerShell에서 실행".
방법 3 (추천):  처음에 start.bat 을 한 번 실행하면 "Run StudyBridge.lnk" 바로가기가
               이 폴더에 자동으로 생깁니다. 그 다음부터는 그 바로가기를 더블클릭하세요.
               (자동 생성이 안 되면 "Make Shortcut.bat" 을 한 번 실행하면 만들어집니다.)

- 맨 처음 실행하면 필요한 파이썬 패키지를 자동으로 깝니다(1~2분, 1회만).
- 잠시 뒤 브라우저가 http://127.0.0.1:8080 으로 자동으로 열립니다.
- 서버는 별도 창에서 돌아갑니다. 그 창을 닫으면 서버가 꺼집니다.
- 다시 실행하면 이전에 켜둔 서버를 자동으로 끄고 새로 켭니다.

[ 사용 순서 (준비 화면) ]
----------------------------------------------------------------
1단계  과목 추가  - 과목 이름, 시험 날짜, 시험 범위, 공부 가능 시간 입력.
       그리고 과목 안의 "단원(실라버스) 정하기"에서 단원을 한 줄에 하나씩
       적거나, 없으면 "AI로 만들기"를 누릅니다.
2단계  자료 올리기 - PDF/워드/PPT/엑셀/이미지/텍스트 등 자유롭게 업로드.
3단계  맞추기     - "AI로 맞추기"를 누르면 각 자료가 어느 단원인지 추측합니다.
       맞는지 확인하고 필요하면 직접 바꾼 뒤 "이대로 확정".
4단계  생성       - "공부자료 생성"을 누르면 진행바가 뜨고, 끝나면 학습 화면으로
       이동합니다. 자료 없는 단원은 AI 생성 여부를 먼저 물어봅니다
       (AI가 만든 내용에는 "AI 생성" 표시가 붙습니다).

- 학습 화면 : 단원별 정리/문제 보기, 추가 질문, "PDF로 저장 / 인쇄".
- Print & PDF : 왼쪽 메뉴 "Print & PDF". 과목을 고르고 둘 중 하나를 만듭니다.
               1) Study Book: 표지, 목차, 설명, 단원별 내용과 연습문제, 정답, 엔딩 페이지.
               2) Problem Set: 단원/문제 종류(정리본 연습문제, 풀었던 퀴즈, 틀렸던 문제)를
                  골라 이름/날짜/점수 칸과 풀이 공간이 있는 문제지로 만듭니다.
                  정답은 뒤에 넣거나 뺄 수 있고 순서 섞기도 됩니다.
               저장된 모의고사도 여기서 PDF로 뽑을 수 있습니다.
               바로가기: 과목 화면의 "Print & PDF" 카드, 모의고사 옆 "PDF",
               학습 화면의 "Problem set PDF"(그 단원만).
               이미 만든 자료만 쓰므로 AI 비용이 들지 않습니다.
- 계획표    : 날짜별 일정. 직접 수정/완료 체크/줄 추가 가능.

[ 문제가 생기면 ]
----------------------------------------------------------------
logs 폴더 안의  studybridge_(오늘 날짜).log  파일을 그대로 보내주세요.
모든 단계와 오류 내용이 시간과 함께 기록되어 있어서 바로 원인을 찾을 수 있습니다.

자주 있는 경우:
- "AI 기능이 안 돼요"      -> OpenAI_Key.txt 에 키가 제대로 들어갔는지 확인.
- "패키지 설치 실패"        -> 인터넷 연결 확인 후 다시 실행.
- "Python을 찾을 수 없음"   -> python.org 에서 파이썬 3 설치 후 다시 실행.
